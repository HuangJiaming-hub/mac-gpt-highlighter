# Codex 三色荧光笔

在 Mac 桌面版 Codex 的聊天原文上划重点。拖选回答中的一段文字，松手后点 **🔴 红、🟡 黄或 🔵 蓝**。标记会跟着文字滚动，下次通过荧光笔打开同一条回答时可以继续读。

**[下载 Mac 版（ZIP）](downloads/codex-tricolor-highlighter-mac.zip?raw=1)** · 预编译包适用于 Apple 芯片 Mac，最低系统版本为 macOS 15。需要已安装包含 Codex 的 ChatGPT 桌面客户端。

## 第一次使用

1. 解压 ZIP，把「三色荧光笔.app」拖进「应用程序」，双击打开。
2. 如果 ChatGPT 已经打开，点「等待退出」。等手头的任务完成，回到 ChatGPT 按 **⌘Q**。荧光笔会自动重新打开客户端。
3. 打开一个已有或新建的聊天，拖选同一条回答中的文字，再点颜色。要改色或擦除，重新选中标记，点另一种颜色或「擦除」。擦除会移除与选区相交的整条标记。

完全退出客户端后，下次请从「三色荧光笔」打开。可以把它放进程序坞。用普通 ChatGPT 图标启动时，已保存的标记会保留，等下次通过荧光笔启动时显示。

## 兼容性与数据

这是独立的社区工具。已在 Apple 芯片 Mac 上用桌面客户端 **26.1106.51428** 的独立测试窗口验证三色选择。客户端更新可能改变消息结构，影响颜色菜单或旧标记的定位。

启动器通过本机进程之间的专用管道，在客户端聊天页面加载随包附带的脚本。脚本通过 CSS Custom Highlight API 给文字着色。荧光笔不修改已安装的客户端文件，也不监听网络端口。

选中的文字、相邻的一小段上下文、颜色和定位信息保存在当前客户端配置的本地存储中。荧光笔不上传这些数据。清除客户端本地数据会移除标记。标记仅保存在本机。

## 从源码构建

在 macOS 上安装 Xcode Command Line Tools，进入仓库根目录后运行以下命令。预编译包使用本地临时签名，未经过 Apple 公证。如果 macOS 拦截下载的应用，也可以在自己的 Mac 上从源码构建。

```sh
sh scripts/build.sh
```

脚本使用系统自带的 Cocoa 框架和编译工具，生成适用于当前 Mac 架构的 `build/三色荧光笔.app` 和 ZIP，并校验签名与压缩包完整性。

## 测试

有 Python 3 和 Google Chrome 的 Mac 可以运行本地回归测试。测试使用独立临时配置和示例文字，覆盖三色、跨格式选区、改色、擦除、刷新恢复和不同聊天中相同文字的隔离。

```sh
python3 tests/test_highlights.py
```
